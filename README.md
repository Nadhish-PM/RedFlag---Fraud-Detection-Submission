# RedFlag – The Fraud Files

RedFlag is a SQL-based fraud detection project using a transaction dataset of around 200,000 transactions. The project identifies suspicious transaction patterns using SQL queries and helps detect potentially fraudulent users and merchants.

## Fraud Patterns Detected

1. Velocity Fraud
2. Round-Amount Clustering
3. Card Testing
4. Failed-Then-Succeeded
5. Odd-Hour Concentration
6. Mule Accounts
7. Refund Abuse
8. Merchant Collusion
9. Just-Under-Threshold Structuring
10. Dormant-Then-Active
11. Velocity Spike
12. Geographic Impossibility

## Technologies Used

- MySQL
- SQL
- MySQL Workbench

## Project Results

All 12 fraud detection queries were tested using the provided transaction dataset.

Some of the detected patterns include merchant collusion, velocity spikes, unusual transaction timing, refund abuse, and geographically impossible transactions.
